GitHub-forbindelse Ikke forbundet

Nøglen sendes aldrig til andre servere og bliver aldrig lagt i dit repository. Den bruges kun fra din enhed til at opdatere playlist.json direkte på GitHub.

Sådan opretter du en sikker GitHub-nøgle (Fine-grained token) på 30 sekunder
  1. Log ind på GitHub og gå til Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Klik på Generate new token og giv den et navn (f.eks. Playliste-admin).
  3. Under Repository access: vælg Only select repositories og vælg dit video-repository.
  4. Under Permissions → Repository permissions: sæt Contents til Read and write.
  5. Klik på Generate token, kopiér nøglen (starter med github_pat_...) og indsæt den i feltet herover.
